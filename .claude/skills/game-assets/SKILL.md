# Game assets

The art rule in `CLAUDE.md` always applies: real game assets only. Sources and licences are in `docs/assets.md`.

## Token care
- The Dex tables are generated JSON, `pokemon-core/src/commonMain/resources/dex/*.json` (`species`, `forms`, `evolutions`, `regions`, `entries`, `moves`, `learnsets`; about 900 KB in all, one row per line): never read them whole; grep for the species or form you need. Never edit them by hand: change `generate.py` (and `DexParser.kt` if a column changes) and regenerate (CI fails if regenerating changes anything). The JVM and Android read them as resources; the web build gets them built into its code by the `generateDexWebSources` task (nothing generated is committed besides the JSON).
- `assets/sprites`, `assets/animated` and `assets/cries` hold thousands of files: never list them; grep `manifest.tsv` or `animated.tsv`, or count with `ls | wc -l`. Open a sprite image only when you must see it.
- The fetch scripts download a lot: run them only when the assets have to change, and keep `tools/species/cache` (git-ignored) between runs.

## Dex data and assets
- `tools/species/generate.py`: stdlib Python that regenerates the Dex JSON from the public PokeAPI CSVs. Run `python3 -I tools/species/generate.py`; it caches downloads in `tools/species/cache` (git-ignored).
- `assets/sprites/`: Pokémon sprites (96×96 PNG, `<formId>.png` and `<formId>-shiny.png`, plus `manifest.tsv`) from the public PokeAPI/sprites repo, fetched with `python3 -I tools/sprites/fetch.py` (needs `tools/species/cache`, so run the species generator first). Form ids match `FormInfo.id`.
- `assets/animated/` and `assets/cries/`: the real Black/White animated sprites (Gen 1 to 5, `python3 -I tools/sprites/fetch_animated.py` converts the PokeAPI GIFs to sprite sheets plus `animated.tsv`; needs Pillow for that step only) and the real cries of species 1 to 1025 (`python3 -I tools/sprites/fetch_cries.py`). `AnimatedSprite` plays a sheet (still `Sprite` for species without one), `CryPlayer` plays a cry (Android MediaPlayer, web audio element, none on desktop); both honour Sound and Reduce motion.
- `assets/sfx/`: a few real game sound effects (select, jump, heal, escape, the Pokémon Center jingle) from hexparrot/pokemon-assets, as mono Ogg (`python3 -I tools/sprites/fetch_sfx.py`, needs ffmpeg). Each is an `Sfx` value played by `CryPlayer.effect` beside the cry player, so a cry and an effect never cut each other off.
- `assets/pmd/`: the preferred Pokémon sprites, Mystery Dungeon style from the PMD SpriteCollab (pinned commit; `python3 -I tools/sprites/fetch_pmd.py`, needs Pillow and `assets/sprites/manifest.tsv`). Sheets of the front-facing Idle row in the `animated.tsv` format (`pmd.tsv`) plus `credits.tsv`; the Sleep, Eat and Hop rows in `pmd/sleep`, `pmd/eat`, `pmd/hop` (each with its own `.tsv`, played by `AnimatedSprite`'s `action`); and `pmd/portraits` (one 40 px strip per form of the faces in `fetch_pmd.py`'s `EMOTIONS`, listed with their artists in `portraits.tsv`, drawn by `Portrait`). `AnimatedSprite`, `Sprite` and the widget art try `pmd` first, then `animated`, then `sprites`. A full run takes about 25 minutes. CC BY-NC 4.0: each Pokédex entry credits the artists. **Extra rows, faces and shinies:** `python3 -I tools/sprites/fetch_pmd.py extra` adds `idle-side`, `idle-up`, `rotate`, `wake`, `deep-breath` and `pose` (each with its own `.tsv`; `SpriteAction`), `fetch_pmd.py faces` rebuilds only the portraits (14 faces in `EMOTIONS`; neither touches `pmd.tsv` or `credits.tsv`), and `python3 -I tools/sprites/derive_shiny.py` recolours every form that has no real shiny from its still sprites (`derived-shiny.tsv`; delete that file and run it after a fetch). The build bundles `assets/animated` only for forms not in `pmd.tsv`.
- `assets/scenes/`: real Pokémon scene backdrops (Showdown, `python3 -I tools/sprites/fetch_scenes.py`) for each region's scene (`BuddyScene.PLAN`, the city, is Plan's town; `BuddyScene.CARE` is Care's meadow; `RegionLook` in composeApp) and the Pokédex entries, where `BuddyScene.of` picks one from the type; `BuddyScene.darkness` dims them at night.
- `assets/items/`: real item icons from PokeAPI/sprites (`python3 -I tools/sprites/fetch_items.py`), used for the tab icons and the bag.
  `fetch_items.py extras` (no species cache needed) adds every `*-berry.png` and `*-mail.png` to `assets/items` (receipt `berries-mail.tsv`) and the 77 badges to `assets/badges/N.png`; badges 1 to 40 are bundled for Plan's goal cases, the Berry and Mail icons are not bundled into the app yet.
- `assets/hoenn/` (REP-053, the modules' places): Pokémon Emerald art from pret/pokeemerald at a pinned commit, no ROM (`python3 -I tools/sprites/fetch_pret.py`, stdlib only, cached in git-ignored `tools/sprites/cache-pret`, receipt `manifest.tsv`): `decorations/` (43 Secret Base sprites, 24 px indexed PNG whose palette colour 0 is a green that means transparent, plus `brendan`, `may` and `decoration_menu` `.pal`), `secret-base/` (the primary and six secondary tilesets: `tiles.png` is greyscale indices drawn with `palettes/NN.pal`, `metatiles.bin` (8 u16 per metatile: two 4-tile layers, tile id | flip x << 10 | flip y << 11 | palette << 12), `metatile_attributes.bin`; `layouts/<Name>/map.bin`, `layouts.tsv` for sizes), `berry-trees/` (six 16 x 32 frames per sheet), and **`room/`**, made from those by `python3 -I tools/sprites/compose_secret_base.py` (Pillow; skips existing files): the six size-1 rooms as ready pictures (`tree`, `shrub`, `red_cave`, `brown_cave`, `blue_cave`, `yellow_cave`, 176 x 144, the game's own `map.bin` laid out from the tileset) and the 42 decorations as transparent RGBA PNGs (`decorations/`); these two are what the Gradle build bundles (`files/hoenn/`) for the Base module's Room (`screens/BaseRoom.kt`). Rule 4.0: this is the art of module places; Mystery Dungeon maps stay with WORLD.
- `assets/rescue-maps/`, `assets/tiles/rr-NN.png`, `assets/pmd-sfx/`: Red Rescue Team maps (`python3 -I tools/sprites/fetch_rescue_maps.py`, no ROM needed: pret/pmd-red commits the map data), dungeon tilesets (`python3 -I tools/tiles/extract_rescue_tiles.py ROM.gba --pret <pmd-red checkout>`) and sound effects (`python3 -I tools/sprites/extract_rescue_audio.py ROM.gba OUT`, then `build_sfx_catalog.py <pmd-red checkout>` for `triggers.tsv`). The ROM is the owner's, never in the repo (SHA-1 `9f4cfc5b5f4859d17169a485462e977c7aac2b89`); only raw.githubusercontent.com is reachable from the cloud sandbox, so a pret checkout is `git clone` through the session's git proxy. The sound renders are approximate: see `assets/pmd-sfx/README.md`.
- `assets/sky-maps/`, `assets/tiles/ex-NNN.png`: Explorers of Sky maps and dungeon tilesets from the owner's ROM (SHA-1 `5fa96ca8d8dd6405d6cd2bad73ed68bc73a9d152`): `python3 tools/sprites/extract_sky_maps.py ROM.nds`, `python3 tools/tiles/extract_sky_tiles.py ROM.nds` (also each tileset's full autotile set, `ex-NNN-auto.png`, for the launcher's dungeon floor) and `python3 tools/tiles/extract_sky_floor.py ROM.nds` (the floor's trap tiles and item pictures, `floor-traps.png`, `floor-items.png`), `python3 tools/sprites/extract_sky_effects.py ROM.nds` (every effect animation into `rip/sky/effects`, and the town's trap effects into `assets/tiles`), `python3 tools/rip/rip_sky.py ROM.nds` (the reference rip in `rip/sky/`: text, scripts and dialogue, tables, portraits, backgrounds; see its README), in a venv with `pip install ndspy skytemple-files "pillow<11"` (PyPI is reachable; Pillow 11+ breaks SkyTemple's palette code). Explorers of Sky sound is DSE (`SOUND/*.swd`, `.smd`, `.sed`): SkyTemple's library has no parser for it, so `python3 tools/sprites/extract_sky_audio.py ROM.nds OUT --kinds se,me,bgm` has its own (from ppmdu's format notes, cloned through the git proxy: `git clone https://github.com/PsyCommando/ppmdu`); music ids are in pret/pmd-sky `include/enums.h` (`bgmNNNN` = id NNNN + 1). Approximate; not audited by ear.
- `tools/sprites/fetch_pmd_new.py` adds named newer SpriteCollab forms (a table in the script, each inspected first) to `assets/pmd` without re-fetching everything; `tools/sprites/pmd_audit.py --cache DIR [--write]` audits which species have PMD sprites in SpriteCollab and its forks (blobless clones, reads only) and writes `docs/ASSETS/PMD_SPRITE_MANIFEST.json`. SpriteCollab's `tracker.json` is behind its folders: trust `AnimData.xml` and the tree. Unapproved fork sprites are PERMISSION_PENDING and stay out of `assets/`.
- `assets/backgrounds/`: Black/White PC box wallpapers from PKHeX, tiled behind each tab by `PixelBackground` (see `docs/assets.md` for sources and licences).

## Module region curation
- `docs/region-curation-prompt.md` (with a brief per region) and `docs/region-candidates.md` (every hatchable line, its tier and the module region it is in): the kit for curating a module region's list in `tools/species/regions/<region>.txt` (`plan.txt`, `care.txt`, `household.txt`, one per `Region` entry with `isModule`; the generator refuses a species in two lists, and a missing file is an empty, uncurated region). Regenerate the candidates table with `./gradlew :pokemon-core:curationReport`.
